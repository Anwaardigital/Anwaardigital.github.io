Complete Guide to Markdown

Markdown is the plain-text way to write formatted documents: README files, blog posts, notes and documentation all use it. Headings use # symbols, **bold** and *italic* add emphasis, backticks mark code, and dashes make lists. Because it is plain text, Markdown files work everywhere, last forever, and convert cleanly to HTML, PDF or Word.

This editor converts your Markdown to HTML instantly, in your browser — nothing is uploaded. Use it to draft GitHub READMEs, blog posts or notes, then copy the HTML straight into your site or download the .md file for later.
