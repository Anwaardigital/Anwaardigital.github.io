💡 Why this matters:

Your WiFi is the front door to every device in your home — phones, laptops, smart TVs, cameras. A weak WiFi setup lets a neighbor (or anyone parked outside) spy on traffic, steal files, or attack your devices. The good news: one careful configuration session fixes almost all of it.

About This Tool

What this tool does

The Wi-Fi Security Checklist walks you through securing your home wireless network step by step. Your Wi-Fi router is the gateway to every device in your home — phones, laptops, smart TVs, cameras — so a weak router password or outdated encryption puts all of them at risk.

The checklist covers the essentials: changing default admin credentials, using WPA3 (or WPA2) encryption, creating a strong Wi-Fi password, setting up a guest network, updating router firmware, and disabling risky features. Each item is a concrete action you can complete in a few minutes.

It is for home users, parents, and small offices — anyone who owns a router. Everything here is defensive: these are the settings on your own equipment that keep intruders off your network. Work through the list once, then revisit it whenever you get a new router or notice unknown devices on your network.

How to use it

  1. Open the checklist and log in to your router's admin page (usually an address like 192.168.1.1, found on the router's label).
  2. Work through each item in order, checking them off as you complete them.
  3. Change the router's admin password first — the default credentials printed on the label are public knowledge.
  4. Set your Wi-Fi encryption to WPA3 if available, otherwise WPA2, and create a long, unique Wi-Fi password.
  5. Enable the guest network for visitors and smart-home devices, keeping them separate from your main devices.
  6. Check for a firmware update and install it, then note the date so you remember to check again in a few months.

Defensive security tips

  • Never keep default passwords. Default router admin credentials are published online and are the first thing an intruder tries.
  • Use WPA3 or WPA2 only. Older WEP and WPA encryption can be broken quickly; if your router only offers WEP, it is time to replace it.
  • Create a guest network. Visitors and smart-home gadgets do not need access to your computers and file shares. Isolation limits the damage if one device is compromised.
  • Update firmware regularly. Router updates fix security flaws. Enable automatic updates if your router offers them.
  • Turn off remote administration and WPS. Managing your router from the internet and the WPS quick-connect feature both add unnecessary attack surface for a home network.

FAQs

Is it safe to use public Wi-Fi?

Use it cautiously. Avoid logging into banking or entering passwords on open public networks unless you are using a VPN, and prefer your phone's mobile data for sensitive tasks. Never change important account settings over public Wi-Fi.

How often should I change my Wi-Fi password?

There is no need for frequent scheduled changes if the password is strong and unique. Change it when someone you no longer trust had access, when a device is lost, or if you suspect unauthorized users on your network.

Does hiding my network name (SSID) help?

Very little. Hidden networks are still easy to discover with basic tools, and hiding the name can cause connection problems. A strong password and WPA2/WPA3 encryption are what actually protect you.

What do I do if I see an unknown device on my network?

Change your Wi-Fi password immediately, which disconnects all devices, then reconnect only the ones you recognize. Also change the router admin password and check for firmware updates.
